# Oxlint Plugin

该插件在 Claude Code 中提供 `oxlint` 技能，用于检查与修复 JavaScript / TypeScript / Vue 项目的 lint 问题。

## 包含内容

- `.claude-plugin/plugin.json`：插件元数据
- `skills/oxlint/SKILL.md`：技能定义

## 使用方式

在安装包含该插件的 Marketplace 后执行：

```
/plugin install oxlint@agents-plugin-marketplace
```

技能会在需要时自动被 Claude Code 调用。
